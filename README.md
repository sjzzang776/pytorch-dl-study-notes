## 무엇을 직접 만들었고, 무엇을 교재에서 가져왔나

- **설명:** 교재 본문을 옮겨 싣지 않고, 스터디원이 읽기 쉽게 새로 썼습니다. 각 절의 끝에 교재의 해당 절 주소와, 교재와 다르게 한 부분을 적어 두었습니다.
- **그림:** 모두 matplotlib 코드로 직접 그렸습니다. 교재의 그림은 쓰지 않았습니다.
- **실습 코드:** 상당수가 교재의 실습 코드를 바탕으로, 데이터·모델·출력을 바꾸거나 새로 짠 것입니다. 기초 장(3~5장)은 교재 코드와 같은 줄이 많습니다. 실습 결과는 모두 직접 실행해서 얻은 값입니다.
- **인용:** 교재의 예시 문장이나 공개된 실행 결과를 짧게 인용한 곳이 있으며, 인용한 곳마다 출처를 밝혔습니다.
- **확인 문제와 해설:** 직접 만들었습니다.

## 데이터셋과 모델

실습에 쓴 데이터셋과 사전 훈련 모델은 이 저장소에 포함하지 않았습니다. 실습 코드는 각 출처(GitHub, Hugging Face, 공개 기관 자료 등)에서 직접 내려받으며, 각 데이터와 모델의 이용 조건은 원래 출처를 따릅니다. 자료에 쓴 출처는 각 실습 코드의 첫 부분과 PDF의 출처 표기에 적혀 있습니다.
